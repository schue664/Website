schue-drechselkunst – Originaldesign mit zusätzlichen Produktkategorien

Das ursprüngliche Design wurde beibehalten. Ergänzt wurden Navigation und Bereiche für:
- Vasen
- Brotkörbe
- Salzdosen / Pfeffermühlen

Für diese drei Kategorien waren keine eindeutigen Produktfotos vorhanden; deshalb enthalten sie vorerst einen kurzen Beschreibungstext und eine Kontaktmöglichkeit statt falscher Bildzuordnungen.

Öffnen: index.html im Browser oder in VS Code mit Live Server.
Beim Veröffentlichen den gesamten Ordner inklusive images hochladen.
